Harbour Lights — a spot-the-difference hunt in a small fishing harbour at dusk. Two near-identical harbour pictures side by side, 3 rounds of rising difficulty (7, 10, then 12 differences), gold-ring markers, hints, a draining timer and a time bonus. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a difference in either picture; H for a hint, R to restart the round, M to mute.
